# SEION AutoPart AI

A localization and compliance workbench for **Tier-2 automotive suppliers in India**. Upload a customer BOM full of DIN / ISO / EN parts and the app:

1. **Matches each line to its Indian Standard (IS) equivalent** from a curated, plant-editable standards library. The matches are deterministic, never generated by AI.
2. **Checks every swap with engineering rules**: property class, tensile and yield strength, hardness, thread fit, near-equivalent and coating warnings (e.g. zinc flake needs IS 16647).
3. **Compares domestic suppliers** on price, lead time and BIS licence / IATF 16949 / ISO 9001 status, and shows honest per-unit, per-vehicle and annual deltas, including when the IS part costs more.
4. **Drafts RFQs** from a template that asks for the BIS licence, EN 10204 3.1 mill test certificates and PPAP readiness. You can copy the RFQ or open it in your mail app, mark it sent, and record the quote. A quote updates the price list and re-prices the BOM line.
5. **Tracks the plant decision and the customer approval** separately (Not submitted → Submitted → Approved / Rejected, with ECN / PPAP reference).
6. **Exports a proposal pack** for PPAP / ECN submission: a print-to-PDF document with sign-off blocks, plus CSV.

Why this scope: see [docs/market-research.md](docs/market-research.md). Requirements and design: [docs/prd.md](docs/prd.md) and [docs/spec.md](docs/spec.md).

## Quick start

Requires **Node.js 22.13 or newer** and pnpm. You don't need a database server, an account or an API key.

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 and click **Try the sample BOM** or **Load demo data**, or upload your own `.xlsx`, `.csv` or text-based `.pdf` (up to 4 MB). You can download a header template from the BOMs page.

On first run the app creates `data/seion.db` and seeds it with:
- 39 standards and 29 equivalences (fasteners, sheet and alloy steels, coatings)
- 6 sample suppliers with indicative prices

These are all labelled **Seed**. Replace them with your own approved suppliers and plant-verified equivalences.

To explore with realistic data, use **Settings → Load demo data**. It adds two demo BOMs with accepted, submitted and approved swaps, RFQs in every state, and three months of savings history.

Node prints a one-line `ExperimentalWarning` for `node:sqlite`; it is harmless.

## Production

```bash
pnpm build
pnpm start
```

Or with Docker (data persists in a volume):

```bash
docker build -t seion-autopart .
```

```bash
docker run -p 3000:3000 -v seion-data:/app/data seion-autopart
```

| Environment variable | Purpose |
| --- | --- |
| `DATABASE_PATH` | SQLite file location (default `./data/seion.db`; `/tmp/seion/seion.db` on serverless hosts) |
| `SEION_DEMO_DATA` | `1` / `0`: load the demo BOMs, decisions and RFQs into a new database. Default: on for serverless (temporary) storage, off otherwise |
| `GROQ_API_KEY` | Optional. Enables AI extraction **only** for BOM files whose header row can't be recognised. Those rows are sent to Groq. |
| `PORT` | HTTP port for `pnpm start` (default 3000) |

**Deployment notes**
- **No login.** The app is designed for a single plant on a trusted network. If you expose it, put an authenticating reverse proxy or a VPN in front.
- **Vercel / serverless = demo mode.** The project directory is read-only there, so the database goes to `/tmp` and demo data is loaded automatically. Uploading BOMs and every workflow work, but data resets whenever the instance restarts and isn't shared between instances; a banner says so. Uploads are capped at 4 MB to fit Vercel's request limit.
- **For real use, use a persistent disk:** a VM, a plant PC or a container with a volume (or point `DATABASE_PATH` at one).
- **Backup.** Copy `data/seion.db` while the app is stopped.

## Development

```bash
pnpm test
```

```bash
pnpm typecheck
```

`pnpm test` runs the unit and integration tests (domain engines, plus the import, match, decide, RFQ and export pipelines against in-memory SQLite). `pnpm typecheck` runs `tsc`.

| Path | Contents |
| --- | --- |
| `app/(workbench)/` | Pages: dashboard, BOMs, BOM workbench, RFQs, suppliers, standards, savings, settings |
| `app/print/boms/[id]` | Printable proposal pack |
| `lib/db/` | SQLite connection, migrations, seed |
| `lib/repo/` | SQL repositories |
| `lib/ingestion/` | CSV / XLSX / PDF parsing and header normalisation |
| `lib/matching/` | Spec canonicalisation and equivalence lookup |
| `lib/validation/` | Engineering rules engine |
| `lib/boms/` | Import and re-match pipelines, savings math, CSV export |
| `lib/rfq/` | RFQ template and quote workflow |
| `lib/actions/` | Server actions |
